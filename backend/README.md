# Backend

This backend is a Maven multi-module project containing:

- identity-service
- event-service

Open `backend/pom.xml` in IntelliJ IDEA as a Maven project. IntelliJ will import both services automatically.

Run Event Service with `ro.eusebiu.event_service.EventServiceApplication`.
Run Identity Service with `ro.eusebiu.identityservice.IdentityServiceApplication`.
